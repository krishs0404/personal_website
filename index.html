FEATURED PROJECT / 2026↗

AgentServe

An inference engine that understands the agent.

An OpenAI-compatible LLM inference engine with Llama 3.2 implemented from the ground up, safetensors weight loading, and a paged KV-cache allocator.

Llama 3.2→Paged KV cache→Agent-aware batching

Continuous batching with priority, overflow, and preemption policies designed around DAG completion time. Prefix KV caching uses LFU eviction to reuse shared prompts.

A benchmark harness measures throughput, time to first token, and latency against FIFO scheduling and vLLM.
